# FC27 Career

Career-mode tracker for EA SPORTS FC 27: squad, deals, finances and each league's real 2026/27 rules.

**Open: https://finnpetersen00.github.io/fc27-career/**

Install it like an app (no App Store):
- **iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the link in Chrome, tap the menu, then **Install app**.

Your career is saved on your phone only. Use Settings > Export Save to back it up or move it.
